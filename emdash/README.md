# Лендинг «Премьер» на EmDash

Та же страница, что `lp/` (имплантация зубов в Набережных Челнах), но тексты, цены, врачи и контакты правятся в админке EmDash, а не в коде. Дизайн, чертежи, калькулятор и окно записи — прежние.

Статическая версия в `lp/` и сайт на GitHub Pages этой папкой не затрагиваются.

## Запуск на своём компьютере

Нужен Node.js 22.16 или новее (лучше 24 LTS): https://nodejs.org

```bash
git fetch origin
git switch emdash          # ветка с EmDash-версией
cd emdash
npm install                # 1–3 минуты при первом запуске
npm run dev
```

Без git: скачать архив ветки https://github.com/Anthon88-nch/premier-dental-landing/archive/refs/heads/emdash.zip, распаковать, открыть папку `emdash` в терминале и выполнить `npm install` и `npm run dev`.

Дальше в браузере:

1. **http://localhost:4321/_emdash/admin** — мастер первого запуска. Название сайта любое, в вопросе «С чего вы хотите начать?» выбрать **«Демо-материалы»** (Sample content) — так загрузится весь текущий лендинг: тексты, цены, врачи, фото. Затем создаётся админ: почта и ключ входа (passkey — Windows Hello, отпечаток или телефон).
   Если passkey сейчас неудобен, для локальной проверки есть вход без него: **http://localhost:4321/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin** — создаст тестового админа dev@emdash.local и загрузит тот же демо-контент. Работает только в `npm run dev`, на боевом сервере выключен.
2. **http://localhost:4321/** — сам лендинг.

Фото врачей и лаборатории при первой загрузке скачиваются с GitHub Pages (`anthon88-nch.github.io/premier-dental-landing/assets/…`), нужен интернет.

Начать с нуля: остановить `npm run dev` (Ctrl+C), удалить `data.db` и папку `uploads`, запустить снова.

## Где что править

| Раздел админки | Что там |
|---|---|
| **Клиника: контакты и цены** → «Основные настройки» | Телефон, адрес, часы, WhatsApp/Telegram/MAX, цена коронки, доплата за одномоментную установку, удаление, консультация, All-on-4 «от», рассрочка, вычет, доп. услуги в калькуляторе, рейтинг и число отзывов, реквизиты, SEO главной, Метрика, noindex |
| **Импланты** | Osstem, Dentium, Astra Tech: цена, абатмент, срок службы, страна, порядок. Галочка «Основной имплант» — его цена «зуб под ключ» идёт в первый экран и в токен `{зуб}` |
| **Врачи и команда** | ФИО, группа, специальность, опыт, фото, ссылка на ПроДокторов, порядок |
| **Страницы** → «Главная — имплантация» | Все блоки лендинга по порядку: заголовки, тексты, карточки, вопросы. Блоки можно переставлять, удалять и добавлять |
| **Меню** → «Меню в шапке» | Пункты навигации |

После правки — «Опубликовать» и обновить страницу сайта.

### Цены считаются сами

Зуб под ключ = имплантат + абатмент и формирователь + коронка. Поменяли цену Osstem или коронки — меняется всё: первый экран, чертёж, карточки вариантов, сравнение имплантов, калькулятор, вопросы. Чтобы так работало и в текстах, вместо цифр пишутся токены:

| Токен | Что подставится (сейчас) |
|---|---|
| `{зуб}` | зуб под ключ на основном импланте — 55 500 ₽ |
| `{имплант}` / `{абатмент}` / `{система}` | цена имплантата / абатмента основного импланта / его название (Osstem) |
| `{коронка}` | 20 000 ₽ |
| `{одномоментная}` | зуб под ключ + доплата — 65 000 ₽ |
| `{доплата}` | доплата за одномоментную установку — 9 500 ₽ |
| `{консультация}` | 1 000 ₽ |
| `{all-on-4}` | 300 000 ₽ |
| `{вычет}` | максимум налогового вычета — 19 500 ₽ |
| `{рассрочка}` | условия рассрочки текстом |
| `{рейтинг}`, `{отзывы}`, `{отзывам}`, `{дата-рейтинга}` | 5,0 · 344 отзыва · 344 отзывам · 22.10.2026 |
| `{телефон}` | телефон, как показывается на сайте |
| `{цены-тыс}` | «18, 30 и 66 тысяч» — для заголовка сравнения |

Опечатка в токене видна на сайте как есть, например `{зубб}`.

### Разметка в текстах

- `*слова*` — курсив (в заголовках это вторая, «рукописная» часть: `Имплантация *во сне*`);
- `**слова**` — жирный;
- `[текст](#vrachi)` — ссылка: на раздел страницы, `/страницу` или `https://…`.

Неразрывные пробелы (после «в», «на», перед тире, в «55 500 ₽», «3–4 месяца», «All-on-4») сайт ставит сам — писать текст можно обычными пробелами.

## Что пока зашито в код

Чертежи (зуб в разрезе, мини-схемы, флаги), подписи «Имплантат / Зуб под ключ / Срок службы», строки спецификации в калькуляторе, кольцевая надпись на печати гарантии. Картинка для соцсетей `public/lp/media/og.png` статичная, на ней цена 55 500 ₽ — при смене цены её нужно перерисовать (или задать картинку в SEO-панели страницы).

## Устройство

- `seed/seed.json` — схема (коллекции, 15 типов блоков, меню) и демо-контент. Генерируется из текущего лендинга; проверка: `npm run seed:check`.
- `src/components/blocks/` — по компоненту на тип блока, `src/components/art/` — чертежи и флаги.
- `src/lib/site.ts` — загрузка «Клиники», «Имплантов», «Врачей» и токены; `src/lib/text.ts` — разметка и неразрывные пробелы.
- `public/lp/` — стили, шрифты и скрипт лендинга (калькулятор берёт цены из страницы, а не из кода).
- `.github/workflows/emdash-check.yml` — проверка на каждый push в ветку `emdash`: сборка, запуск, правка цены через CLI EmDash и скриншоты.

## Перед публикацией в интернет

Пока это локальная версия — на хостинг ничего не выкладывалось. Для боевого запуска нужен сервер с Node.js (VPS: `npm run build`, затем `npm start`, база — файл `data.db`) или Cloudflare (D1 + R2). Решим после просмотра.
