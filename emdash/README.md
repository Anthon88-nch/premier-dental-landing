# Лендинг «Премьер» на EmDash

Та же страница, что `lp/` (имплантация зубов в Набережных Челнах), но тексты, цены, врачи и контакты правятся без кода — прямо на странице или в админке. Дизайн, чертежи, калькулятор и окно записи прежние. Статическая версия `lp/` и GitHub Pages этой папкой не затрагиваются.

## Запуск на Windows

Нужен Node.js 22.23.4 или новее (24 LTS или 26): https://nodejs.org. Git не нужен.

**Первый раз** — в PowerShell:

```powershell
cd D:\Work
Invoke-WebRequest -UseBasicParsing https://github.com/Anthon88-nch/premier-dental-landing/archive/refs/heads/emdash.zip -OutFile premier-emdash.zip
Expand-Archive premier-emdash.zip -DestinationPath D:\Work
```

Дальше двойной клик по **`D:\Work\premier-dental-landing-emdash\emdash\start.cmd`**. При первом запуске он сам поставит зависимости (1–3 минуты), запустит сайт и откроет браузер. Окно `start.cmd` не закрывать, пока работаете; остановить — Ctrl+C.

- Сайт: http://localhost:4321/
- Админка: http://localhost:4321/_emdash/admin — при первом входе мастер настройки: в вопросе «С чего вы хотите начать?» выбрать **«Демо-материалы»**, затем создать админа (почта и ключ входа — Windows Hello, отпечаток или телефон). Для локальной проверки можно без ключа: http://localhost:4321/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin

**Обновить** до свежей версии: остановить `start.cmd`, запустить **`update.cmd`** из той же папки. Он скачает новые файлы и спросит, сбросить ли базу к демо-контенту — сбрасывать нужно, если в обновлении менялась админка (свои правки при этом пропадут).

## Как править

### Прямо на странице

1. Войдите в админку, откройте сайт (http://localhost:4321/).
2. Внизу экрана — плашка EmDash: включите **«Режим редактирования»**.
3. Кликайте на любой текст, кнопку, цену или подпись — появится поле правки. **Enter** — сохранить и сразу опубликовать, **Esc** — отменить, **Shift+Enter** — новая строка в длинных текстах.

Цены пересчитываются сами: поменяли цену Osstem в карточке имплантов или коронку в блоке лаборатории — обновятся первый экран, чертёж, карточки вариантов, калькулятор и вопросы. «Зуб под ключ» и итоги сметы считаются из этих цен — по клику на них подсказка, где менять.

В режиме правки ссылки и кнопки не срабатывают — клик открывает правку. Чтобы проверить сайт как посетитель, выключите режим в плашке.

### В админке

То, что не текст: фото (клик по фото в режиме правки откроет нужную запись в админке), ссылки, порядок и состав блоков, меню, флажки стран, SEO, Метрика.

| Раздел | Что там |
|---|---|
| **Страницы → Главная — имплантация** | Все блоки лендинга по порядку: добавить, убрать, переставить |
| **Клиника** → «Контакты и цены» | Телефон, адрес, часы, мессенджеры, цены (коронка, доплата, консультация, All-on-4), рассрочка, вычет, доп. услуги, рейтинг, реквизиты, SEO, Метрика |
| **Импланты** | Цена, абатмент, срок службы, страна, какой основной |
| **Врачи и команда** | ФИО, группа, специальность, опыт, фото, ПроДокторов |
| **Меню** | Пункты в шапке |

### Подсказки по тексту

- `*слова*` — курсив (в заголовках это вторая, «рукописная» часть), `**слова**` — жирный, `[текст](#vrachi)` — ссылка.
- Цены в тексте можно писать токенами — тогда они меняются вместе с ценами: `{зуб}` (зуб под ключ), `{имплант}`, `{система}` (Osstem), `{коронка}`, `{одномоментная}`, `{доплата}`, `{консультация}`, `{all-on-4}`, `{вычет}`, `{рассрочка}`, `{рейтинг}`, `{отзывы}`, `{отзывам}`, `{дата-рейтинга}`, `{телефон}`, `{цены-тыс}` («18, 30 и 66 тысяч»). В поле правки они видны как есть, на сайте — цифрами.
- Неразрывные пробелы («в Челнах», «55 500 ₽», «3–4 месяца», «All-on-4») сайт ставит сам.

## Если не открывается

- «Не удаётся получить доступ к сайту» — сайт не запущен: окно `start.cmd` закрыто.
- Порт 4321 занят — точный адрес написан в окне после `Local`.
- «Не найден Node.js» или «npm не является командой» — установить Node.js и открыть окно заново.
- Первое открытие админки — 10–30 секунд.
- Фото при первом запуске скачиваются с GitHub Pages — нужен интернет.

## Что пока зашито в код

Кольцевая надпись на печати гарантии, подписи «Имплантат / Зуб под ключ / Срок службы», строки спецификации в калькуляторе. Картинка для соцсетей `public/lp/media/og.png` статичная, на ней цена 55 500 ₽.

## Устройство

- `seed/seed.json` — схема (коллекции, 15 типов блоков, меню) и демо-контент; проверка: `npm run seed:check`.
- `src/components/blocks/` — компонент на каждый тип блока; `src/components/art/` — чертежи и флаги.
- `src/lib/site.ts` — «Клиника», «Импланты», «Врачи» и токены; `src/lib/text.ts` — разметка и неразрывные пробелы.
- `src/lib/edit.ts` и `src/components/EditKit.astro` — правка на странице: разметка мест правки и редактор (сохраняет через API EmDash и публикует).
- `public/lp/` — стили, шрифты и скрипт лендинга.
- `.github/workflows/emdash-check.yml` — проверка на каждый push в ветку `emdash`: сборка, запуск, правка на странице, правка цены через CLI, скриншоты, запуск на Windows.

## Перед публикацией в интернет

Пока только локально. Для боевого запуска нужен сервер с Node.js (VPS: `npm run build`, затем `npm start`, база — файл `data.db`) или Cloudflare (D1 + R2).
